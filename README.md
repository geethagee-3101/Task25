# TASK 25 – BASIC DATA VALIDATION

## Project Overview
This project focuses on creating a data-entry sheet with dropdown menus and validation rules using Microsoft Excel and Google Sheets.

The main objective is to improve spreadsheet data quality by preventing invalid, duplicate, and inconsistent entries.

## Tools Used
- Microsoft Excel
- Google Sheets

## Dataset
Synthetic Employee Data

### Columns
- Employee ID
- Employee Name
- Department
- Job Role
- Employment Type
- Joining Date
- Age
- Email
- Monthly Salary
- Status

## Features Implemented
1. Dropdown lists for Department, Job Role, Employment Type, and Status.
2. Age validation (18–65).
3. Salary validation (positive values only).
4. Joining Date validation.
5. Basic email format validation.
6. Duplicate Employee ID detection.
7. Conditional formatting to highlight duplicate IDs.
8. Highlighting missing required fields.

## Excel Implementation
- Used Data Validation to create dropdown lists.
- Applied number and date restrictions.
- Used custom formulas to check duplicate IDs and email formats.
- Applied conditional formatting to identify errors.

## Google Sheets Implementation
- Uploaded the Excel workbook to Google Drive.
- Opened the workbook using Google Sheets.
- Reviewed dropdown lists and validation rules.
- Used Data → Data validation to configure or recreate rules where necessary.

## Sample Data
Added 10 synthetic employee records to demonstrate the validation features.

## Learning Outcomes
- Learned how to create dropdown lists.
- Understood spreadsheet data validation.
- Learned to prevent invalid data entry.
- Practiced conditional formatting.
- Improved Excel and Google Sheets skills.

## Conclusion
This task demonstrates how data validation helps maintain accurate, consistent, and reliable spreadsheet data. Dropdowns and validation rules reduce manual errors and improve overall data quality.
